## Usage

<code>[XMLRead]()[*text*]</code> reads an XML 1.0 document to symbolic XML: <code>XMLObject["Document"][*prolog*, *element*, *epilog*]</code>.

## Details & Options

- An element is <code>[XMLElement]()[*name*, {*attribute* -> *value*, ...}, {*content*, ...}]</code>, its content strings, elements, `XMLObject["Comment"][text]` and `XMLObject["ProcessingInstruction"][target, text]`.
- The prolog holds `XMLObject["Declaration"]["Version" -> ..., ...]`, `XMLObject["Doctype"][name, ...]`, comments and processing instructions, in order; the epilog what follows the root element.
- The parser is generated by [EBNFParse]() from [XMLEBNF](), the grammar of the W3C Recommendation; its token rules are regular expressions.
- Names stay as they are written, prefix and all, and no whitespace is dropped. Text next to text is one string, a CDATA section and a reference among it.
- The option `"Entities"` gives the entities beyond the five of XML, an [Association]() of names to their text. A reference to an entity it does not have stays in the text between `\[EntityStart]` and `\[EntityEnd]`.
- An internal subset of a document type is kept as text under `"InternalSubset"`: its declarations are not read.
- Text that is not a well-formed document gives a [Failure](): one the grammar does not take, with the `"Position"` where reading stopped, or one that breaks a constraint the grammar cannot state, an end tag that names another element, an attribute given twice, a character reference to no character.

## Basic Examples

A document:

```wl
XMLRead["<a x='1'>t<b/></a>"]
```

<!-- => XMLObject["Document"][{}, XMLElement["a", {"x" -> "1"}, {"t", XMLElement["b", {}, {}]}], {}] -->

## Scope

A declaration, a comment, references, a CDATA section and a processing instruction:

```wl
XMLRead["<?xml version='1.0'?><!-- c --><doc><p id=\"a&amp;b\">x &lt; y<![CDATA[ <z> ]]></p><?pi go?></doc>"]
```

<!-- => XMLObject["Document"][{XMLObject["Declaration"]["Version" -> "1.0"], XMLObject["Comment"][" c "]}, XMLElement["doc", {}, {XMLElement["p", {"id" -> "a&b"}, {"x < y <z> "}], XMLObject["ProcessingInstruction"]["pi", "go"]}], {}] -->

## Options

### Entities

An entity the option gives is its text:

```wl
XMLRead["<a>&e;</a>", "Entities" -> <|"e" -> "E"|>]
```

<!-- => XMLObject["Document"][{}, XMLElement["a", {}, {"E"}], {}] -->

## Possible Issues

A start tag that is not closed:

```wl
XMLRead["<a><b></a>"]
```

An attribute given twice:

```wl
XMLRead["<a x='1' x='2'/>"]
```
